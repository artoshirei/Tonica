# Tonica 1.1.0

Tonica is now a native AppKit harmony reference for guitarists, pianists, and songwriters.

* A resizable circle of fifths with stable major and relative minor selection.
* All seven diatonic chords, their notes, and common progressions you can copy.
* Piano keys and a standard guitar fretboard with scale, chord, and root highlights.
* Hear notes, chords, and ascending scales without loading samples or using the network.
* A permanent near-black interface and matching native Settings for window behavior, launch, keyboard shortcut, and updates.
* Click the menu bar icon to open Tonica. Right-click for settings, updates, and quit.
* A static menu bar symbol removes continuous background animation.
* Correct F♯ spelling and enharmonic matching between neighboring keys.
* Copy confirmations clear automatically and retain the current key’s chord labels.
* Clearing the global shortcut now stays cleared after relaunch.

The updater keeps its existing feed and signing identity. Releases are built, signed, notarized, and verified locally before publication.
